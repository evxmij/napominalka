# Покрытие ТЗ: текущий статус реализации

Легенда: ✅ реализовано, 🟡 частично, ❌ не реализовано.

## 1) Цель
- Таймер/напоминания/дневник/статистика/план/бэкап в приложении: 🟡 (есть каркас, не полный production-функционал).

## 2) Платформа и ограничения
- Android API 26+: ✅
- Offline-first: 🟡 (локальная БД есть, но часть сценариев еще не связана end-to-end).
- RU язык: 🟡 (большинство строк RU, но нет полноценного i18n).
- Светлая/тёмная тема: 🟡 (Material3 подключен, переключатель темы не реализован).
- Локальные данные + JSON backup: ✅ (есть Room + export/import manager).

- Привязка к теме/задаче: ❌

### Напоминания

### Оценка дня

### План/задачи

- Задачи с чекбоксом/приоритетом/дедлайном: 🟡 (модель есть, UI заглушка).
- Статус темы: 🟡 (поле есть, нет полного CRUD).

### Статистика
